# Data source inventory

Evaluated against: tiers covered, access method, cost, rate limit, latency, history depth, commercial use.

**Gate:** unclear or prohibited commercial licensing makes a source unusable for anything beyond personal/research use, regardless of how good the data is. That's a hard block on this list, not a tradeoff.

## What's actually clear to build on today

- **Basketball-Reference**: clear for commercial use with attribution, within stated rate limits. Best default free source for historical stats/box scores.
- **SportsDataIO**: clear once on a paid commercial plan. This is the realistic path to officially-licensed real-time NBA data without a five-figure Sportradar contract.
- **Sportradar**: clear but budget-gated — revisit if/when the product has revenue or funding to support it.

## Blocked or unresolved — do not wire into `commercialUseCleared` providers yet

- **nba_api / stats.nba.com** — matches the brief's existing `NBA_STATS_ENABLED` opt-in gate for exactly this reason; keep it there, don't promote it to auto-selected.
- **RealGM** — hard no without written permission.
- **Spotrac** — no license chain for programmatic use; needs Spotrac's direct confirmation.
- **Kalshi** — needs Kalshi's written consent for the trade-predictor use case specifically (it's an AI/software product using their data, which their terms call out by name).
- **Polymarket** — needs a full read of their ToS (not just API docs) before relying on it commercially.

## Confidence note

Pricing, rate limits, and terms above were pulled from public docs/search in August 2026 and are a starting point, not a legal clearance. Anything marked "unverified" or "unclear" above should be confirmed with the provider directly (or by a human reading the actual ToS end-to-end) before it gates a real launch decision — this doc is not a substitute for that.
